## Cómo trabajo

- **Reglas de negocio protegidas en la base de datos:** transacciones y bloqueos para que dos usuarios no puedan reservar el mismo horario ni comprar la misma última unidad.
- **Pruebas automatizadas e integración continua:** en mis proyectos Laravel cada push ejecuta los tests en GitHub Actions; en el ecommerce, además, el formateo con Pint y el análisis de calidad con SonarCloud.
- **Interfaces accesibles y rápidas:** HTML semántico, contraste adecuado y navegación por teclado.
- **Documentación pensada para quien llega después:** cada proyecto explica qué resuelve, cómo instalarlo y por qué se tomó cada decisión.
